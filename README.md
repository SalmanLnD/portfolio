# Muhammed Salman — Portfolio

Training Leader · Software Engineer · AI & EdTech Builder.

Live: [sfmuhammedsalman-portfolio.onrender.com](https://sfmuhammedsalman-portfolio.onrender.com)

## Local

```bash
npm install
npm run dev
```

## Deploy on Render

1. Push this repo to GitHub.
2. In Render, create a **Static Site** from the repo.
3. Set the service name to `sfmuhammedsalman-portfolio` (URL becomes `sfmuhammedsalman-portfolio.onrender.com`).
4. Build command: `npm install && npm run build`
5. Publish directory: `dist`
